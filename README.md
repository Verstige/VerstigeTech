# VerstigeTech

> **Live trading analytics & strategy performance for the 9-engine algorithmic fleet.**

A high-level analytics dashboard that pulls live signal data, P&L, and
backtest results from the trading engine database and surfaces them in a
glass-dark, premium UI styled after the [VerstigeOS landing page](https://verstige.io).

## 🌐 Live URL

**[https://verstige.github.io/VerstigeTech/](https://verstige.github.io/VerstigeTech/)**

Hosted via GitHub Pages on the `gh-pages` branch. Refreshes every 5 minutes via cron.

## 📦 Pages

| Page | URL | What's there |
|---|---|---|
| **Overview** | `/` | Hero, KPI strip, engine grid, daily P&L chart, strategy catalog teaser |
| **Strategies** | `/strategies.html` | All 9 engines, strategy deck style with entry/exit/filters per engine |
| **Live Dashboard** | `/dashboard.html` | Real-time P&L, click-to-filter engine, Telegram health, open trades |
| **Analytics** | `/analytics.html` | Win rate by engine, profit factor, cumulative P&L curve, per-engine breakdown |
| **Backtests** | `/backtests.html` | 7d / 30d / 60d / 90d comparison with per-engine ranking |
| **Performance** | `/performance.html` | Best/worst trade, P&L distribution histogram, top winners/losers |
| **Risk** | `/risk.html` | Max drawdown, current DD, max consecutive wins/losses, Sharpe, exposure bars, correlation matrix |
| **Trade Log** | `/tradelog.html` | Searchable, sortable, filterable full ledger of all closed trades |

## 🎨 Design

Styled after the VerstigeOS landing page:
- **Outfit** + **JetBrains Mono** fonts
- **Code rain** background (animated falling characters)
- **Glass panels** with frosted backgrounds
- **Glow gradients** for accent cards
- **Gold / cyan / purple / emerald / pink** accent system
- **Dark theme**: deep navy/black with electric accents

## 🔧 Stack

- Pure static HTML — no build step, no framework
- **Chart.js 4.4** via CDN for charts
- **Chart.js** theme: dark grid lines, JetBrains Mono labels
- 9-engine fleet rendered via shared `assets/site.js` + `assets/styles.css`

## 🔄 Data flow

```
[Mac running trading engines]
  └─ verstige_trades.db (SQLite, canonical store)
        ↓
  scripts/build_dashboard.py (every 5 min via cron)
        ↓
  data/dashboard.json (consumed by dashboard.html + every other page)
        ↓
  GitHub Pages (gh-pages branch)
        ↓
  https://verstige.github.io/VerstigeTech/ (live)
```

## 🛠 Local dev

```bash
# Serve locally (http://127.0.0.1:8766)
python3.11 -m http.server 8766 --bind 127.0.0.1

# Rebuild dashboard JSON manually
python3.11 scripts/build_dashboard.py

# Override DB path (defaults to ~/Projects/VerstigeOS-Official/src/lib/trading_bot/verstige_trades.db)
VERSTIGETECH_DB=/path/to/db.sqlite python3.11 scripts/build_dashboard.py
```

## 🔐 What VerstigeTech does NOT contain

- ❌ Trading engine code (lives in VerstigeOS-Official)
- ❌ Telegram bot tokens or chat IDs (only channel routing in JSON)
- ❌ Web app (Next.js marketing pages) — not part of scope
- ❌ Any write operations on the trading DB (read-only aggregator)
